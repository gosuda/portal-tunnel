Portal HTTP Inspector

Local, in-memory debugging only. The latest 100 completed transactions are retained. Bodies are off by default; --inspect-bodies / inspect_bodies = true captures up to 8 KiB per body and may expose secrets. Only selected header values are retained. Query values with credential-like names are redacted; paths and other query values may still contain private data.

Replay sends a request directly to the configured upstream through the local router, bypassing public sign-in and payment gates. It can repeat purchases, send messages, or modify data. Redacted headers are omitted; webhook signature or timestamp checks may reject it.
